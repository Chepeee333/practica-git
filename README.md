# Sistema de Inscripción Escolar — Repositorio de práctica (Taller de Git)

Este es un mini-proyecto **intencionalmente incompleto**, pensado para practicar el flujo de trabajo colaborativo de Git en equipo (Sesión 4 del taller). No requiere instalar nada: es HTML, CSS y JavaScript planos.

## Cómo verlo

Abre `index.html` directamente en tu navegador (doble clic, o clic derecho → "Abrir con" → tu navegador).

## Estructura

```
index.html   → estructura de la página
style.css    → estilos y colores
script.js    → validación del formulario de contacto
```

## Cómo se usa en el taller

Cada integrante del equipo trabajará en su propia rama, sobre una tarea distinta marcada con comentarios `TODO` dentro del código. Ve el documento **"Tarjetas de Tarea"** que te entregó tu profesor para instrucciones específicas de tu rol.

No modifiques archivos fuera de tu tarea asignada sin avisar al resto del equipo — ese es, de hecho, el punto central del ejercicio.
